# Hookah Mixer

Помощник для гостя кальянной: по настроению или по конкретному аромату предлагает микс из 3–4 ароматов
с процентами. Бренды и табаки не нужны — микс достаточно назвать кальянщику.

**Сайт:** https://demansh.github.io/hookah-mixer/ · русский и английский.

## Как пользоваться
1. На старте вкладки:
   - **Настроение** — сетка эмодзи, по одному на каждый из 114 образов («Тропические фрукты», «Бледный Петербург»,
     «Тирамису»…). Подписей нет: что было загадано, видно в заголовке карточки после тапа. Пасхалка: если
     зажать эмодзи, вверху появится его название (микс при этом не открывается).
     Порядок постоянный — от привычного к загадочному: классика кальянных вкусов → знакомые напитки, десерты
     и категории → сезоны, погода, природа → места → настроения и цвета (внутри группы — по привычности пар).
   - **Вкус** — 102 аромата по категориям (🍎 садовые фрукты, 🌿 травы…). Тап — микс с этим ароматом.
   - **Шкаф** — отметьте ароматы, которые у вас есть (включая холодок): тап по букве алфавитного указателя
     показывает ароматы на эту букву (точка на букве — там есть отмеченные), блок «В шкафу» сверху — всё
     отмеченное, тап по нему убирает аромат. Затем **🗄️ Микс из шкафа**:
     мастер соберёт микс только из них (кнопка доступна от трёх отмеченных). Шкаф хранится в браузере.
     На карточке «Из шкафа» всё работает как обычно — 🔓, ✕, ↻ и температура берут ароматы только из шкафа.
   - Или кнопка **🎲 Случайный микс** внизу.
   - **★** — избранное: миксы, отмеченные ☆ в углу карточки (повторный тап по ★ убирает). Список только для
     просмотра — состав, доли, цвет температуры и откуда микс; ✕ удаляет из избранного (5 секунд можно
     «Вернуть» из подсказки внизу).
   - **Поделиться** (иконка рядом с ☆ на карточке и у миксов в избранном): на телефоне — системное меню, иначе
     текст «Манго 45% · ананас 45% · холодок 10% — Hookah Mixer» со ссылкой копируется в буфер. Ссылка
     `?mix=mango.45,pineapple.45,cooling.10&tier=classic` открывает карточку только для просмотра (☆, поделиться,
     🏠); формат совпадает со старой версией, поэтому прежние ссылки снова работают (`q` — в заголовок).
2. На карточке микса внизу — градусник мастера (на стартовом экране его нет): **36,6°** — мастер спокоен
   и выдаёт классику, **37,2°** — экспериментирует, **38°** — бредит (смелое сочетание). Переключение сразу меняет
   микс; аватарка мастера слева меняет лицо. Выбранная температура сохраняется для следующих миксов.
3. Карточка микса: цветная полоса пропорций (у каждого аромата свой цвет, точка того же цвета у названия),
   вкусовой профиль — сладость, кислинка, свежесть по 5 точек (среднее по долям из характеристик ароматов ядра).
   Новый микс «собирается» на глазах: строки появляются по очереди, полоса заполняется, проценты досчитывают.
   После ✕ микс не пересобирается, а перетекает: убранный аромат зачёркивается и схлопывается, новый проявляется
   с подсветкой, проценты и полоса плавно меняются от старых значений (при уменьшении движения — без анимации).
4. У каждого аромата в карточке:
   - **🔓 → 🔒** (замочек слева) — оставить во всех следующих миксах (до трёх). Микс не перезагружается:
     можно отметить несколько, отметки применятся при следующем ↻ или смене температуры;
   - **✕** — убрать из микса: на его место встаёт подходящий аромат или он просто пропадает, проценты
     пересчитываются. Убранное видно под карточкой, тап по нему возвращает аромат.
5. **↻** — другой микс с тем же выбором (уже показанные пропускаются), **← Настроение / Вкус / Шкаф / Избранное**
   — назад на вкладку, с которой открыт микс (новое зерно, закрепления сбрасываются, температура остаётся).
6. «Назад» в браузере отменяет последний шаг; всё состояние хранится в адресе страницы.

Всё считается прямо на устройстве, без сервера и ИИ-моделей. Приложение можно установить на телефон
(«На экран Домой» / «Установить приложение») и пользоваться им без интернета. На iPhone у установленного
приложения своё хранилище: шкаф и избранное в нём отдельные от Safari.

## Ядро
База знаний и движок подбора — отдельный репозиторий **hookah-mixer-core** (`~/dev/pet/hookah-mixer-core`).
Приложение получает собранное ядро копией в `assets/core/` (руками не правится):

```bash
(cd ../hookah-mixer-core && npm install && npm run build)
./tools/sync-core.sh        # путь к ядру можно переопределить: CORE_DIR=... ./tools/sync-core.sh
```

Подбор — `recommendSelection({ concepts, required, excluded, seed })`: ядро отдаёт три микса по уровням,
температура выбирает один. ✕ отправляет в ядро оставшиеся ароматы как обязательные (фиксация остатка, `lock` в адресе)
и берёт микс того же размера.

## Устройство
- GitHub Pages + Jekyll (только сборка страницы), Vanilla JS с ES-модулями без сборщика.
- `assets/js/app.js` — каталог, история, загрузка миксов, фиксация остатка по ✕, пропуск показанных, фильтр
  шкафа, избранное; `state.js` — состояние и адрес; `render.js` — экраны, карточка (полоса, профиль, анимация
  сборки); `options.js` — температуры, вкладки, категории; `i18n.js` — строки RU/EN; `shelf.js` — хранение шкафа;
  `favorites.js` — хранение избранного; `share.js` — поделиться; `toast.js` — подсказки внизу и плашка
  с названием вверху; `long-press.js` — тап и долгое нажатие; `flavor-colors.js` — цвета ароматов;
  `master.js` — аватарка; `concept-emoji.js` — эмодзи и порядок образов (`CONCEPT_ORDER`; новые — в конец);
  `icons.js` — иконки Lucide (arrow-left, lock-open, lock-keyhole, share, star, x, refresh-cw).
- Адрес: `?tab=taste|shelf|favorites` (вкладка старта), `?s=mix&c=<образ>&keep=…&drop=…&lock=…&p=N&t=bold`;
  микс по вкусу — `?s=mix&from=flavor&keep=banana`, из шкафа — `?s=mix&from=shelf`; присланный микс —
  `?mix=mango.45,…&tier=classic`.
- `localStorage`: язык — `hm.lang`, шкаф — `hm.shelf` (`{ version: 1, items: [id…] }`), избранное —
  `hm.saved-mixes` (`{ version: 1, items: [{ key, tier, components, source, addedAt }] }`; старое `hm.favorites`
  из прошлой версии намеренно не подхватывается). Ароматы вне шкафа уходят в `excluded` запроса к ядру.
- PWA: `manifest.webmanifest`, иконки в `assets/icons/`, `sw.js` — Jekyll-шаблон: при установке кэширует все
  файлы из `/assets/` (включая ядро), имя кэша = sha сборки (`site.github.build_revision`), старые кэши удаляются.
  Запросы — «сначала сеть», без сети — из кэша (параметры адреса игнорируются, поэтому открываются и карточки).
- Превью ссылок (Telegram и др.): Open Graph в `_layouts/default.html` — название, описание из `_config.yml`
  и иконка `icon-512.png`. Превью одинаковое для любой ссылки, включая `?mix=…`: мессенджеры не выполняют JS.
- Безопасность: строгий Content Security Policy, пользовательские данные выводятся только как текст.
