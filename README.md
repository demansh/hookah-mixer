# Hookah Mixer

Помощник для гостя кальянной: по описанию настроения предлагает три микса из 3–4 ароматов с процентами.
Бренды и конкретные табаки не нужны — микс достаточно назвать кальянщику.

**Сайт:** https://demansh.github.io/hookah-mixer/ · работает в браузере и устанавливается на телефон как приложение.

## Как пользоваться

1. Внизу экрана опишите, чего хочется: «свежие тропические фрукты с холодком», «ягодный чай», «овсянка»,
   «Бледный Петербург» — или нажмите на пример в ленте чипов (её можно крутить в обе стороны).
2. Нажмите ✨ — появятся три микса. Цвет полоски слева показывает смелость:
   🟢 классика с изюминкой · 🟡 эксперимент · 🔴 смелое сочетание.
3. Не понравилось — нажмите ↻ ещё раз: каждое нажатие даёт новые варианты без повторов.
4. Уточняйте прямо из карточки: **+** у аромата добавляет его в каждый микс, **−** убирает его из всех миксов.
   Это же можно написать словами: «манго с мятой, без кокоса».
5. Эмодзи-мастер слева от поля подсказывает, как понят запрос: 🧙 пустой запрос (мастер колдует случайные
   миксы), 😊 понял ароматы, 🤩 понял образ, 🤔 догадался по части запроса, 😕 не понял (тоже даст случайные
   миксы), 🧐 есть исключения, 😅😰🥵 вы перегенерируете уже не первый раз.

## Как запрос превращается в микс

Всё считается прямо на устройстве, без сервера, интернета и ИИ-моделей — за доли секунды.

1. **Разбор запроса.** Во фразе ищутся названия ароматов («манго», «ромашка»), образы («Масленица», «мохито»,
   «что-то кислое») и свойства вкуса («свежее», «сливочное»). Понимаются разные формы слов («клубничный»,
   «с мятой») и отрицание «без X». Аромат, названный прямо, обязательно войдёт в каждый микс.
2. **Вкусовой профиль.** Каждый образ заранее расписан как набор ароматов с весами: «Закат на Мальдивах» —
   это манго, маракуйя, ананас и кокос.
3. **Соседи.** По карте сочетаемости подтягиваются ароматы, которые хорошо идут с запрошенными, — так в миксах
   появляется то, о чём гость не подумал.
4. **Перебор.** Проверяются тысячи комбинаций из 3–4 ароматов. Отбрасываются конфликтующие пары, два слишком
   интенсивных аромата в одном миксе, три аромата одной категории, приторные и чересчур кислые сочетания.
5. **Три уровня смелости.** Каждая пара в карте помечена как классическая, известная или редкая. Классика
   опирается на привычные пары с одной неожиданной, смелое сочетание — на редкие, но гармоничные. У трёх
   карточек разные основные ароматы.
6. **Проценты.** Основа получает 40–55%, акценты 15–30%, холодок 5–15%. Интенсивные ароматы (корица, гвоздика,
   анис) ограничены, чтобы не перебить остальные; шаг — 5%.
7. **Немного случайности.** Порядок среди почти равных по качеству миксов слегка перемешивается, поэтому после
   перезагрузки тот же запрос даёт другие варианты, а внутри сессии перегенерация идёт без повторов.

## База знаний

Четыре файла в `data-src/` — их правят вручную, проверяет и собирает в JSON скрипт `tools/build.py`:

| Файл | Что внутри | Объём |
|------|-----------|-------|
| `tags.csv` | ароматы и свойства вкуса: названия и синонимы RU/EN, категория, роль в миксе (основа, акцент, поддержка, холодок), интенсивность 1–5, сладость/кислотность/свежесть 0–5, описание | 103 аромата + 6 свойств |
| `pairings.csv` | карта сочетаемости: оценка пары от −1 до +1, привычность (классика/известная/редкая), пояснение RU/EN | ~1200 пар |
| `category_affinity.csv` | сочетаемость категорий — запасная оценка для пар, которых нет в карте | 171 пара |
| `concepts.yaml` | образы: фразы → ароматы с весами и что исключить; понятные образы помечены для показа в чипах | ~110 образов, ~660 фраз |

Собранные файлы лежат в `assets/data/` (около 190 КБ) — руками их не правят.

## Устройство

- **Стек:** GitHub Pages + Jekyll (только сборка страницы), Vanilla JS с ES-модулями без сборщика,
  Python + `uv` для инструментов. Интерфейс на русском и английском.
- **PWA:** манифест и service worker («сначала сеть», без интернета — сохранённая версия). Иконка — колба.
- **Безопасность:** строгий Content Security Policy, пользовательский ввод выводится только как текст.

```
index.html, _layouts/          страница, CSP, мета PWA
_data/i18n/{ru,en}.yml         тексты интерфейса
assets/js/engine/              движок: text (словоформы), profile (разбор), graph, mixes (пул и перебор),
                               shares (проценты), recommend (уровни, страницы), random (зерно)
assets/js/ui/                  форма, лента чипов, карточки, эмодзи-мастер, нижняя панель
assets/data/                   собранная база
data-src/                      исходники базы знаний
tools/validate.py, build.py    проверка и сборка базы
sw.js, manifest.webmanifest    PWA
.claude/skills/                инструкции и скрипты для AI-агента, который сопровождает проект
```

## Разработка

```bash
uv sync                          # Python-окружение
uv run tools/validate.py         # проверить базу знаний
uv run tools/build.py            # собрать assets/data/*.json
git push                         # GitHub Pages пересобирает сайт за 1–2 минуты
```

Отладка на устройстве: `?debug=1` — лог, версия сборки, зерно случайности и кнопка сброса кэша;
`?seed=N` — воспроизвести конкретную выдачу.
