# Hookah Mixer

Помощник для гостя кальянной: по настроению или по конкретному аромату предлагает микс из 3–4 ароматов
с процентами. Бренды и табаки не нужны — микс достаточно назвать кальянщику.

**Сайт:** https://demansh.github.io/hookah-mixer/ · русский и английский.

## Как пользоваться
1. На старте две вкладки:
   - **Настроение** — сетка эмодзи, по одному на каждый из 114 образов («Тропические фрукты», «Бледный Петербург»,
     «Тирамису»…). Подписей нет: что было загадано, видно в заголовке карточки после тапа.
     Порядок постоянный — от привычного к загадочному: классика кальянных вкусов → знакомые напитки, десерты
     и категории → сезоны, погода, природа → места → настроения и цвета (внутри группы — по привычности пар).
   - **Вкус** — 102 аромата по категориям (🍎 садовые фрукты, 🌿 травы…). Тап — микс с этим ароматом.
   - **Шкаф** — отметьте ароматы, которые у вас есть (те же ароматы плюс холодок), и нажмите **🗄️ Микс из шкафа**:
     мастер соберёт микс только из них (кнопка доступна от трёх отмеченных). Шкаф хранится в браузере.
     На карточке «Из шкафа» всё работает как обычно — ♡, ✕, ↻ и температура берут ароматы только из шкафа.
   - Или кнопка **🎲 Случайный микс** внизу.
2. Внизу всегда градусник мастера: **36,6°** — мастер спокоен и выдаёт классику, **37,2°** — экспериментирует,
   **38°** — бредит (смелое сочетание). Переключение сразу меняет микс; аватарка мастера слева меняет лицо.
3. У каждого аромата в карточке:
   - **♡** — оставить во всех следующих миксах (до трёх). Микс не перезагружается: можно отметить несколько,
     отметки применятся при следующем ↻ или смене температуры;
   - **✕** — убрать из микса: на его место встаёт подходящий аромат или он просто пропадает, проценты
     пересчитываются. Убранное видно под карточкой, тап по нему возвращает аромат.
4. **↻** — другой микс с тем же выбором (уже показанные пропускаются), **🏠** — на главный экран (на ту вкладку,
   с которой открыт микс).
5. «Назад» в браузере отменяет последний шаг; всё состояние хранится в адресе страницы.

Всё считается прямо на устройстве, без сервера и ИИ-моделей.

## Ядро
База знаний и движок подбора — отдельный репозиторий **hookah-mixer-core** (`~/dev/pet/hookah-mixer-core`).
Приложение получает собранное ядро копией в `assets/core/` (руками не правится):

```bash
(cd ../hookah-mixer-core && npm install && npm run build)
./tools/sync-core.sh        # путь к ядру можно переопределить: CORE_DIR=... ./tools/sync-core.sh
```

Подбор — `recommendSelection({ concepts, required, excluded, seed })`: ядро отдаёт три микса по уровням,
температура выбирает один. ✕ отправляет в ядро оставшиеся ароматы как обязательные («замок» `lock` в адресе)
и берёт микс того же размера.

## Устройство
- GitHub Pages + Jekyll (только сборка страницы), Vanilla JS с ES-модулями без сборщика.
- `assets/js/app.js` — каталог, история, загрузка миксов, замок, пропуск показанных, фильтр шкафа;
  `state.js` — состояние и адрес; `render.js` — экраны; `options.js` — температуры, вкладки, категории;
  `i18n.js` — строки RU/EN; `shelf.js` — хранение шкафа; `master.js` — аватарка; `concept-emoji.js` — эмодзи
  и порядок образов (`CONCEPT_ORDER`; новые образы — в конец); `icons.js` — иконки Lucide (heart, x, refresh-cw).
- Адрес: `?tab=taste|shelf` (вкладка старта), `?s=mix&c=<образ>&keep=…&drop=…&lock=…&p=N&t=balanced|bold`;
  микс по вкусу — `?s=mix&from=flavor&keep=banana`, из шкафа — `?s=mix&from=shelf`.
- `localStorage`: язык — `hm.lang`, шкаф — `hm.shelf` (`{ version: 1, items: [id…] }`). Ароматы вне шкафа
  уходят в `excluded` запроса к ядру.
- Безопасность: строгий Content Security Policy, пользовательские данные выводятся только как текст.
