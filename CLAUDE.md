# Hookah Mixer — контекст проекта для AI-агента

Состояние на 2026-10-27. Сайт: https://demansh.github.io/hookah-mixer/.
Это **веб-приложение** (интерфейс). База знаний и движок подбора — репозиторий **`~/dev/pet/hookah-mixer-core`**
(свои `README.md`, `CLAUDE.md`, скиллы `fix-query-handling`, `add-knowledge`, `release-to-app`). Правки данных,
распознавания и логики миксов — там. **Все изменения интерфейса делаем здесь** (решение пользователя
2026-10-27). `~/dev/pet/hookah-mixer-lab` — бывшая песочница, из которой пришёл этот интерфейс; её не обновляем.
История решений и планы: `~/ai/hookah-mixer/` (текущий интерфейс — `09-lab-thermometer.md`).

## Что это
GitHub Pages + Jekyll, Vanilla JS ES modules без сборщика, mobile first, RU/EN. Гость выбирает идею
(эмодзи образа на вкладке «Идеи»), аромат на вкладке «Вкусы» или собирает микс из своего «Шкафа» (`hm.shelf`)
и получает один микс из 3–4 ароматов с процентами. Градусник мастера 36,6° / 37,2° / 38° = classic / balanced / bold.
🔓/🔒 — закрепить аромат, ✕ — убрать с заменой, ↻ — другой микс, «← вкладка» — назад к выбору.
Подробности и адреса — в `README.md`.

## Пользователь и правила работы (обязательно)
- Общение и документация — на русском.
- Данные пишет агент (в ядре); пользователь даёт отзывы о вкусе и сообщает о странных выдачах.
- **Никаких комментариев в коде** (включая docstrings). **Никаких unit-тестов**.
- Агент **не коммитит и не пушит**: в конце даёт команду `git add -A && git commit -m "..." && git push`.
  Локальный `user.email` репозитория — `demansh17@gmail.com`. Коммит в `master` = сразу деплой.
- Пользователь проверяет на реальном телефоне через задеплоенный GitHub Pages. Не предлагать эмуляторы, adb,
  туннели, Safari-отладку, локальный Jekyll.
- UI максимально компактный. Любой текст UI — через `assets/js/i18n.js`, сразу на ru и en.
- Безопасность: строгий CSP в `_layouts/default.html`, вывод только через `textContent`.
- Эмодзи — не новее Emoji 13 (2020), без лиц в сетке образов (лица — у аватарки мастера). Иконки — Lucide
  (лицензия `assets/icons/LICENSE-lucide.txt`).
- Планы сохранять в `~/ai/hookah-mixer/` (≤100 строк, ≤120 символов в строке, разделы: запрос пользователя,
  краткое содержание, основная часть).

## Ядро в приложении
- `assets/core/` — копия `dist/` ядра. **Руками не править.** Обновление: в ядре `npm run build`, здесь
  `./tools/sync-core.sh` (процесс — скилл `release-to-app` ядра).
- Импорт только публичного API `../core/js/index.js`. Используется: `loadCatalog`, `recommendSelection`,
  `createSessionSeed`, `flavorLabel`, `isIngredient`, `MAX_REQUIRED_FLAVORS`.

## Проверка UI (агент)
`bundle exec jekyll build -d /tmp/...`, раздать `python3 -m http.server`, headless Chrome: скриншоты
(`--window-size=500,…` — уже 500px не бывает; `--force-prefers-reduced-motion`, чтобы не ловить анимацию)
и сценарии кликов через временную копию `index.html` с подключённым тестовым скриптом, результат — `--dump-dom`.
Язык браузера — `--accept-lang=ru-RU` (флаг `--lang` в headless не работает).
Service worker через `--dump-dom` не проверить: Chrome с `--remote-debugging-port` и скрипт на Python
(`uv run --with websocket-client`), офлайн — `Network.emulateNetworkConditions`. Локальная сборка подставляет
в `sw.js` sha текущего коммита (`site.github.build_revision`).
